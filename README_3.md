# نظام الموارد البشرية الداخلي (Supabase) — الإصدار 3

ملفان فقط: `schema.sql` (قاعدة البيانات والصلاحيات) و`index.html` (الواجهة).

## ماذا يفعل النظام
- **المسؤول (أنت):** يرى كل البيانات، يسند المهام، يقيّم الأداء، يراقب لوحة الأرقام، يطّلع على سجل الوصول للهويات، **ينزّل الصور**، ويصدّر Excel.
- **عضو الفريق:** يسجّل بيانات الأعضاء ويعدّلها ويرفع الصور، يسلّم مهامه، ويعبّئ استبيان التفاعل. ولا يرى إلا ما أدخله هو أو أُسند إليه.
- صور الهوية والصور الشخصية في تخزين **خاص**، وتُعرض بروابط مؤقتة، ويُسجَّل في `access_log` كل **فتح أو تنزيل** لصورة هوية.
- الصلاحيات مفروضة داخل قاعدة البيانات نفسها (RLS).

## الجديد في الإصدار 3

**بيانات العضو (بدل بيانات الموظف)**
- رقم العضوية (بدل الرقم الوظيفي) — فريد لكل عضو.
- الاسم الكامل بالعربية (يُرفض أي اسم بحروف غير عربية أو أقل من ثلاثة أسماء).
- رقم الهاتف، **المحافظة** (قائمة منسدلة بمحافظات مصر الـ27)، العنوان، **رقم البطاقة** (14 رقماً، ولا يتكرر).
- **الصفة** (قائمة منسدلة): رئيس، نائب، عضو، عضو مركزي، ممثل.
- بعد اختيار الصفة **تظهر أزرار اختيار** اللجنة / جهة التمثيل: المكتب الإعلامي، الموارد البشرية، التنظيم والمراسم، التدريب والتطوير، العلاقات العامة والدولية، الاستدامة والتحول الأخضر، السياحة والثقافة، التخطيط والمتابعة، ممثل مكتب المشروعات، ممثل المكتب الفني.
- رفع الصورة الشخصية وصورة الهوية يظل متاحاً للمسؤول وكل من يدخل البيانات.

**البحث والتصفية**
- بحث بالاسم أو رقم العضوية (يتجاوز اختلاف الهمزات والتاء المربوطة والأرقام العربية/الهندية، ويدعم عدة كلمات).
- أزرار **الكل / نشط / غير نشط** مع عدّاد لكل حالة.

**الصور**
- نافذة «بيانات العضو» (زر العين) تعرض كل الحقول والصورتين، **وبجانب كل صورة زر تنزيل** يحفظها على جهازك باسم العضو (للمسؤول فقط).
- صورة الهوية لا تُفتح تلقائياً: زر «عرض» يسجّل الفتح، وتنزيلها يُسجَّل أيضاً في سجل الوصول.

**تصدير Excel (بدون صور)**
- ملف `.xlsx` منسّق: عنوان وتاريخ التصدير وعدد السجلات، رؤوس ملوّنة بألوان الموقع، صفوف متبادلة اللون، حالات ملوّنة (نشط/غير نشط، مرفقة/غير مرفقة…)، اتجاه من اليمين لليسار، تجميد للعناوين، تصفية جاهزة على الأعمدة، وإعداد للطباعة (A4 أفقي وترقيم صفحات).
- رقم البطاقة والهاتف ورقم العضوية تُحفظ كنصوص فلا تتحول إلى صيغة علمية ولا تفقد الأصفار.
- من صفحة الأعضاء: يُصدَّر ما يظهر حسب البحث والتصفية الحالية. ومن لوحة التحكم: ملف واحد بكل البيانات (الأعضاء، المهام، الأداء، التفاعل، سجل الوصول) أو كل جدول على حدة.
- عمودان يوضحان من لديه صورة شخصية / صورة هوية مرفقة، دون وضع الصور نفسها.

## خطوات الترقية من الإصدار 2
1. **SQL Editor ← New query** ← الصق كل `schema.sql` الجديد ← **Run**. آمن لإعادة التشغيل ولا يحذف شيئاً: الرقم الوظيفي القديم يتحول تلقائياً إلى رقم العضوية، والحقول القديمة (القسم/البريد/الانضمام) تبقى في الجدول دون استخدام.
2. استبدل `index.html` بالجديد وأعد رفعه، ثم حدّث الصفحة (Ctrl+F5).
3. الأعضاء المسجَّلون سابقاً سيظهر عليهم وسم «بيانات ناقصة» حتى تستكمل المحافظة والعنوان ورقم البطاقة والصفة واللجنة عبر زر التعديل.

> إن لم تُعد تشغيل `schema.sql` فلن يعمل حفظ الحقول الجديدة.

## خطوات الإعداد لأول مرة
1. **إنشاء المشروع** في Supabase (اختر أقرب منطقة). راجع قانون حماية البيانات الشخصية بخصوص تخزين صور الهوية.
2. **تشغيل `schema.sql`** كاملاً من SQL Editor.
3. **إغلاق التسجيل العام:** Authentication ← Sign In / Providers ← عطّل Allow new users to sign up.
4. **حسابك:** Authentication ← Users ← Add user (فعّل Auto Confirm)، ثم شغّل:
   ```sql
   update public.profiles set role = 'admin' where email = 'your@email.com';
   ```
5. **أعضاء الفريق:** من Add user بنفس الطريقة؛ يظهرون بدور `member`.
6. **ربط الواجهة:** ضع Project URL ومفتاح anon/publishable (وليس service_role) في أعلى كود `index.html` (النسخة المرفقة تحمل القيمتين الحاليتين).
7. **النشر:** Cloudflare Pages أو Netlify Drop أو Vercel، وارفع `index.html`.

## ملاحظات مهمة
- **الخمول:** مشاريع الخطة المجانية تتوقف بعد نحو أسبوع من الخمول؛ يكفي الاستخدام المنتظم أو Restore من لوحة Supabase.
- **النسخ الاحتياطي:** الخطة المجانية بلا نسخ تلقائية؛ صدّر ملف «كل البيانات» دورياً واحفظه في مكان آمن. الصور تُنزَّل من نافذة كل عضو.
- **حجم الصور:** تُضغط تلقائياً قبل الرفع (حد أقصى 1280px).
- **الأعداد الكبيرة:** Supabase يُرجع حتى 1000 صف في الطلب الواحد افتراضياً؛ إن تجاوزتم ذلك أضف ترقيماً من جهة الخادم.
- **الاحتفاظ بالبيانات:** حدّدوا مدة الاحتفاظ بصور الهوية واحذفوها عند انتهاء الحاجة. استبدال صورة من عضو عادي لا يحذف القديمة من التخزين (الحذف للمسؤول فقط).
- **الترويسات:** إن أتاحت الاستضافة إضافة ترويسات HTTP فأضف `X-Frame-Options: DENY` و`Referrer-Policy: no-referrer`.
- ملف Excel يُبنى بمكتبة ExcelJS التي تُحمَّل من jsDelivr عند أول تصدير فقط.
